# elliprof test plan

## Principles

* **The reference implementation is the unchanged MONSTA Fortran.** Tests check the code around it (I/O, preprocessing, coordinates, packaging), check fits against synthetic images with known answers, and guard against drift with stored baselines.
* **Exact where exactness is guaranteed; toleranced only where it isn't.**
  - Preprocessing (sky, mask) is bit-exact.
  - On one platform, all three routes (native CLI, Python API, Python CLI) must give byte-identical `.prf` files.
  - Between platforms, numerical tolerances apply, set from measured spreads.
* **Baselines are never regenerated by a test run.** Only `make update-baselines` (maintenance) writes them.
* **Normal tests avoid known legacy problem areas:** NR ≤ 100, R0 ≥ 3 px, no GC on images over 2048 px.

## How to run

| Command | What it runs |
|---|---|
| `make check` | build, source hashes, `tests/unit`, `tests/integration`, `tests/regression` |
| `make test-unit` / `test-integration` / `test-regression` | one suite |
| `make docker-test` | `make check` inside Ubuntu 24.04 (Linux) |
| `pytest -c tests/packaging/pytest.ini tests/packaging` | against an **installed** wheel (never the source tree) |
| `make notebook-check` | executes `notebooks/elliprof_example.ipynb` |
| `ELLIPROF_SBF_DIR=… pytest tests/unit/test_mask_io.py` | optional check against masks MONSTA itself wrote |

Current counts are 217 source-tree tests (unit 176, integration 8, regression 33) plus 10 installed-wheel tests. One test is skipped unless `ELLIPROF_SBF_DIR` is set.

## 1. FITS reading
* **Input:** synthetic BITPIX −32 images (2-D), a 1-D image, a text file, a missing file.
* **Expected:** 2-D images are read as REAL*4 with BSCALE/BZERO applied (CFITSIO `FTGPVE`, no NULL substitution, as MONSTA's `cfitsdisk.c`).
* **Failure:** a missing file gives `cannot open … CFITSIO status 104`; non-FITS gives `cannot open`; 1-D gives `no 2-D image` (exit 1, before any fit).
* **Where:** `unit/test_native_cli.py`, `unit/test_cli_args.py`.

## 2. FITS origin (CNPIX)
* **Input:** images with and without `CNPIX1/2`, and sky images/masks with a different origin.
* **Expected:** the origin is read as MONSTA's default CNPIX mode does (0 when absent) and added to the output x0/y0. A mask or sky image must have the same origin.
* **Failure:** `has origin (CNPIX1,CNPIX2) = (…) but the image has (…)`, exit 1.
* **Where:** `unit/test_sky.py::test_origin_follows_cnpix`, `test_sky_image_registration`, `unit/test_mask_io.py::test_mask_registration`, `unit/test_regions.py::test_center_uses_origin`.

## 3. Scalar sky (`--sky`, alias `--sc`)
* **Input:** values `3246.0`, `3246`, `3246.6105834960936`, `-12.5`, `1e3`, `0`.
* **Expected:** the prepared image (`--prepare-only --prepared`) equals `float32(data) + float32(-float32(sky))` **exactly**. `--sc` gives an identical result and a deprecation note.
* **Failure:** non-numbers or two tokens give `--sky needs one number`; `--sky` + `--sky-image` gives `only one of`.
* **Tolerance:** none (bit-exact).
* **Where:** `unit/test_sky.py`.

## 4. Sky image (`--sky-image`)
* **Input:** a random float32 sky; a gradient sky (regression case `sky_image`).
* **Expected:** `data − sky` exactly. The regression fit agrees with the equivalent constant-sky case (rel 2e-4, abs 2e-3; A3/A4 phases excluded because their amplitudes are ~0).
* **Failure:** a size or origin mismatch, or a missing file, gives a clear message and exit 1.
* **Where:** `unit/test_sky.py`, `regression/test_synthetic.py`.

## 5. BITPIX = 1 mask decoding
* **Input:** bitmaps written by a transcription of MONSTA's writer `fpbit_`: all-good, all-bad, alternating, checkerboard, odd width, width 1, non-byte-aligned rows, final partial byte for r = 1…7, random 37×53. Also hand-computed byte strings.
* **Expected:**
  - Python (`elliprof.masks.decode_bitmap`) and native (`src/shim/maskio.f`) decoders both return the source array exactly.
  - Explicit byte cases pin the pair swap, low-bit-first order, continuous bitstream across rows, and top-aligned final partial byte.
  - `u12517j.dmask`: 1025×1022, only {0, 1}, 103,402 zeros, 944,148 ones, 0 at (567, 562), 301 zeros in the 41×41 box.
  - Optional: matches masks written by MONSTA itself (all 1,047,550 pixels).
* **Failure:** truncated data, no END card, not FITS, missing file each give a message naming the mask (exit 1); the Python decoder raises.
* **Where:** `unit/test_mask_io.py`.

## 6. Standard FITS masks
* **Input:** uint8, int16 and float32 masks; a 0.5-valued mask.
* **Expected:** the image is multiplied by the mask values (MONSTA `MI`). Values other than 0/1 give a warning, not an error.
* **Where:** `unit/test_mask_io.py`.

## 7. Mask registration
* **Expected:** the mask must have the same size and the same CNPIX. In Python, LTV/LTM must also agree where both files define them. There is never a partial overlap (MONSTA's legacy `MI` used the overlap silently).
* **Failure:** `is W x H pixels but the image is …`, `has origin …` / `has CNPIX1 = …`.
* **Where:** `unit/test_mask_io.py`, `unit/test_cli_args.py`.

## 8. centers.dat
* **Expected:** it has **no special meaning**. A `centers.dat` next to the image is ignored and the automatic centre is used.
* **Where:** `unit/test_coordinates.py::test_no_centers_dat_lookup`.

## 9. Explicit X/Y centre
* **Expected:** `X0=`/`Y0=` and `center=(x, y)` are passed through unchanged.
* **Failure:**
  - only one of X0/Y0 gives `must be given together` (Python CLI exit 2, native exit 1);
  - non-numeric gives `must be numbers`;
  - `X0=` inside Python `extra` is refused (use `center=`);
  - a missing centre in the raw backend gives the message pointing to the Python command.
* **Where:** `unit/test_coordinates.py`, `unit/test_cli_args.py`, `unit/test_native_cli.py`.

## 10. Physical-coordinate centre (IRAF/DS9 LTV/LTM)
* **Input:** no LTV (identity), an LTV sub-image offset, a binned LTM = 0.5.
* **Expected:** `X0 = LTM1_1·X + LTV1 − 0.5`; e.g. physical (150, 80) with LTV = (−100, −50) gives (49.5, 29.5).
* **Failure:** a rotated LTM is refused.
* **Tolerance:** exact.
* **Where:** `unit/test_coordinates.py`.

## 11. RA/DEC centre
* **Input:** a synthetic TAN WCS, decimal and sexagesimal strings, `hms/dms` strings, a Galactic SkyCoord, the real u12517 WCS.
* **Expected:**
  - the WCS reference point maps to CRPIX − 0.5 (1e-9 px);
  - an off-centre round trip is accurate to 1e-7 px;
  - sexagesimal equals decimal (1e-6 px);
  - numbers are read in the WCS's own frame (FK5 for EQUINOX 2000 without RADESYS);
  - a SkyCoord is transformed.
* **Failure:** no celestial WCS gives `no celestial WCS` (never a fallback); unparsable input gives `cannot parse`.
* **Where:** `unit/test_coordinates.py`, `integration/test_equivalence.py::test_u12517_radec_center`.

## 12. Image-centre fallback
* **Expected:** `(NCOL/2, NROW/2)` in ELLIPROF coordinates: (512.5, 511.0) for u12517, (128, 128) for 256², (0.5, 0.5) for 1×1. `Center source: image center` is printed.
* **Where:** `unit/test_coordinates.py`, `integration`, `regression` (`auto_center`), `packaging`.

## 13. ELLIPROF argument parsing
* **Expected:**
  - words are split by MONSTA's own `UPPER`/`DISSECT` (case-insensitive, expressions allowed);
  - at most 16 keywords;
  - the Python keyword builder maps options to words.
* **Failure:**
  - R0/R1/NR missing: `R0=, R1= and NR= are required` / `missing required fit parameters`;
  - GC without NR;
  - `OLD`/`EDIT`: `not supported`;
  - unknown option;
  - option without value.
* **Where:** `unit/test_native_cli.py`, `unit/test_cli_args.py`.

## 14. CSV output
* **Expected:**
  - `#` header with Input, Mask, Sky and Center source;
  - fixed width, 11 comma-separated columns aligned with the name row;
  - values equal the `.prf` within their printed precision (4 or 6 decimals, or 8 significant digits for I0/I3/I4).
* **Where:** `unit/test_profile_io.py`.

## 15. PRF output
* **Expected:** MONSTA `SAVE ELLIPROF=… ASCII` layout: `N_PRF, PRF_SC, PARAM_PRF(12,250), PRF_HEAD`. Contours beyond N are empty; row 12 holds the run flags; `read_profile` returns exact REAL*4 values. The `PRINT EPROF` table matches the `.prf` to its printed precision.
* **Where:** `unit/test_profile_io.py`.

## 16. DS9 output
* **Expected:**
  - ellipse = (x0 − CNPIX1 + 0.5, y0 − CNPIX2 + 0.5, Rmaj, Rmaj(1 − ellip), alpha − 90);
  - N_PRF ellipses (NaN rows left out);
  - no text labels;
  - the synthetic galaxy's outer ellipse is at (127.8, 122.1) with b/a = 0.7 and angle 30° (mod 180).
* **Tolerance:** 5e-5 (4-decimal output).
* **Where:** `unit/test_regions.py`, `regression`.

## 17. MODEL output
* **Expected:** `-m` writes the model. For the synthetic galaxy it is within 2% of the true r^¼ image for 5 < r < 60 px. The model file is byte-identical to the baseline on the same platform.
* **Where:** `regression/test_synthetic.py::test_model_image`, `test_matches_baseline[model]`.

## 18. RMSTAR
* **Expected:** runs on u12517 (structural and plausibility checks, baseline).
* **Tolerance:** cross-platform checks treat RMSTAR cases with the looser rules (a star cut can flip on a threshold).
* **Where:** `regression/test_u12517.py`.

## 19. OLD
* **Expected:** not supported. Refused by the backend and by Python with a clear message, because OLD would silently run with an empty previous profile (zero iterations).
* **Where:** `unit/test_native_cli.py`, `unit/test_cli_args.py`.

## 20. Error handling
Covered in the sections above. Every error listed in the specification ends with exit code 1 or 2 and a message that names the problem. No Fortran `STOP` banner is printed, and errors are caught before the fit wherever the driver can detect them (unwritable output, missing inputs, bad options).

## 21. Python API
* **Expected:** `run_elliprof` returns `ElliprofResult` with profile (DataFrame with the 11 columns), paths, stdout/stderr, returncode, center, center_source, command, version and backend_path. A failure raises `ElliprofError` carrying the result; with `check=False` it returns the result instead. `prepared=` returns the exact image passed to ELLIPROF, equal to `apply_mask(subtract_sky(...))`.
* **Where:** `integration/test_equivalence.py`.

## 22. CLI / Python equivalence
* **Expected:** the native CLI, `run_elliprof`, the Python CLI in-process, and `python -m elliprof` give **byte-identical** `.prf` and `.reg` files, and identical CSV data rows. This holds for an explicit centre, the automatic centre, and sky image + mask.
* **Where:** `integration/test_equivalence.py`, `packaging`.

## 23. Synthetic regression
* **Cases:** circular, elliptical, rotated, offcenter, const_sky, sky_image, star_nomask, star_mask, auto_center, radec_center, noisy, model. These are r^¼ galaxies, 200×200, stored in `tests/data/regression/` and generated once by `make_synthetic.py`.
* **Truth limits** (contours with 5 ≤ Rmaj ≤ 0.8 R1), set at about 3–5× the measured recovery:

  | Quantity | Noise-free | Noisy |
  |---|---|---|
  | centre | 0.05 px | 0.5 px |
  | ellipticity | 0.015 | 0.02 |
  | PA (skipped when circular) | 0.5° | 2° |
  | I0 | 1% | 3% |
  | de Vaucouleurs Re, Ie (major axis), q·Re (minor axis) | 3% | 5% |

  Measured recovery on the noise-free cases: centre ≤ 0.011 px, ellip ≤ 0.010, PA ≤ 0.23°, I0 ≤ 0.4%.
* **Star + mask:** the masked profile's worst I0 error is < 1% and at least 3× smaller than without the mask. Every masked isophote matches the star-free galaxy (rel 2e-3).
* **Baselines:** on the same platform and backend build, byte-identical. On another platform, compared with `tolerances.json` (see §23a).

### 23a. Cross-platform tolerances: measured first, not frozen
`tests/regression/tolerances.json` is marked **PROVISIONAL**. While it is, a cross-platform difference beyond it is reported as an expected failure (xfail) with the measured value, not a failure. The comparison rules are:
- A3/A4 are compared only where I3/I4 > 0.005;
- alpha only where ellip > 0.02;
- phases wrap at 120°/90°.

Measured on 2026-09-24 (full tables in `tests/regression/spread/`):

| Comparison | Result |
|---|---|
| Linux x86_64 vs Linux aarch64 (same toolchain) | bit-identical |
| Linux GCC 14 wheel vs Linux GCC 13 build | identical except A3/A4 ≤ 8e-6° |
| macOS arm64 (GCC 16, Apple libm) vs Linux: synthetic cases excluding circular | x0/y0 ≤ 3.3e-4 px, I0 rel ≤ 4.4e-6, alpha ≤ 2e-4°, ellip ≤ 4.3e-6, slope ≤ 6e-5, I3/I4 ≤ 6e-6, A3/A4 ≤ 0.01° |
| same, u12517 | x0/y0 ≤ 3.0e-3 px, I0 rel ≤ 6.7e-6, alpha ≤ 0.015°, ellip ≤ 1.9e-4, I3/I4 ≤ 8e-5, A3/A4 ≤ 0.07° |
| same, circular | ill-conditioned (undefined PA): x0/y0 ≤ 5e-3 px, I0 rel ≤ 1.8e-3 |
| macOS x86_64, Windows x86_64 | **not measured yet** |

**Proposed final tolerances**, to be confirmed once macOS x86_64 and Windows are measured. They are about 10× the largest well-conditioned spread (u12517), with the circular case given structural checks only:

| Column | Proposed tolerance |
|---|---|
| Rmaj | exact |
| x0, y0 | 0.03 px |
| I0 | rel 1e-4 |
| alpha | 0.15° |
| ellip | 2e-3 |
| slope | 1e-3 |
| I3, I4 | 1e-3 |
| A3, A4 | 1° (only where amplitude > 0.005) |

## 24. Real data: u12517
* **Expected:**
  - the image and mask load, 1025×1022, mask {0, 1} with 103,402 zeros;
  - the centre comes from explicit X0=567 Y0=562;
  - the sky subtraction and mask messages are printed;
  - the fit completes with 23 contours;
  - the `.prf`, CSV and region files exist, with N_PRF = CSV rows = ellipses (finite rows);
  - plausible profile: I0 decreasing outward for r ≥ 20, centre within 3 px, ellip in [0.05, 0.4];
  - byte-identical to the baseline on the same platform.
* This is not a reproduction of the historical SBF pipeline.
* **Where:** `regression/test_u12517.py`.

## 25. Cross-platform builds and packaging
* **Wheel build:** cibuildwheel (`pyproject.toml [tool.cibuildwheel]`); CFITSIO static from the pinned, checksummed source.
* **Wheel repair:** auditwheel / delocate / delvewheel (`--analyze-existing-exes`). `tools/ci/check_backend_deps.py` must report only bundled or OS libraries; a Homebrew-linked build is correctly rejected.
* **Clean install (no compiler):**
  - Linux: `python:*-slim` containers with `ELLIPROF_TEST_REQUIRE_NO_COMPILER=1`.
  - macOS (locally): a sandbox that denies all of `/opt/homebrew`. The un-repaired binary fails there, as it should.
* **Installed-wheel tests** (`tests/packaging`):
  - imports the installed package; backend inside the package;
  - no compiler;
  - `--help`, `--version`, `--diagnostics`, `python -m elliprof`;
  - explicit and automatic centre; scalar sky; sky image + mask;
  - the Python API is byte-identical to the CLI;
  - spaces and non-ASCII in paths (xfail on Windows if unsupported).
* **Build equivalence:** the CMake/wheel-built backend reproduces the Makefile-built baselines **byte for byte** (regression suite run with `ELLIPROF_NATIVE` pointing at the installed wheel).
* **Status per platform:**

  | Platform | Status |
  |---|---|
  | Linux aarch64 | built, clean-tested on Python 3.10 and 3.13 |
  | Linux x86_64 | built, clean-tested on Python 3.12 (emulated) |
  | macOS arm64 | built, sandbox-tested |
  | macOS x86_64 | pending CI |
  | Windows x86_64 | pending CI |
  | Windows ARM64 | unsupported |

* **Docker:** `make docker-test` (Ubuntu 24.04, apt CFITSIO 4.3, GCC 13). It passes natively on aarch64 and emulated on x86_64 (210 passed, 2 skipped, 1 xfail: the circular-case cross-platform difference).

## 26. Source integrity
* **Expected:** SHA-256 of the 9 original Fortran files and 4 include files equal `tests/original_source_hashes.txt`, which is only ever edited by hand. `.gitattributes` keeps them free of line-ending conversion.
* **Where:** `unit/test_source_hashes.py`, first step of `make check` and of CI on every platform.
* **Build configuration:** Makefile and CMake use the same flags and sources, with no preprocessing and no forbidden optimisation or checking flags (`unit/test_build_config.py`).
